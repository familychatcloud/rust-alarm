## นาฬิกาปลุกแบบเน้นที่ไม่มีสิ่งพิเศษที่ไม่เกี่ยวข้อง

Noler เป็นนาฬิกาปลุกแบบเน้นเสียงที่สร้างด้วย Rust โดยจะสร้างการปลุกครั้งเดียวและปลุกซ้ำ พูดป้ายกำกับการปลุกแต่ละรายการดังๆ และเก็บบันทึกและการตั้งค่าการปลุกไว้ในอุปกรณ์ของคุณ

แอปมุ่งเน้นไปที่การเตือนแทนที่จะรวมเข้ากับบริการไลฟ์สไตล์ที่กว้างขึ้น

ไม่มีโฆษณารอหลังจากปิด ไม่มีการวิเคราะห์เพื่อดูว่าคุณใช้แอปอย่างไร ไม่มีบัญชีให้สร้าง ไม่มีบริการคลาวด์ที่ต้องดูแลรักษา และไม่มีเครื่องมือสภาพอากาศ ข่าวสาร ดวงชะตา การติดตามการนอนหลับ หรือการกรนที่ไม่เกี่ยวข้องที่ทำงานอยู่เบื้องหลังสัญญาณเตือนของคุณ

## ฟังจุดประสงค์ของการปลุกของคุณ

เสียงปลุกปกติจะดังขึ้น แต่เมื่อกึ่งตื่น คุณอาจจำไม่ได้ว่าปลุกไว้เพื่ออะไร Noler พูดป้ายกำกับที่คุณเขียนสำหรับการเตือนนั้น:

> “ไปโรงเรียนกันเถอะ”

> “กินยาของคุณซะ”

> “ไปสนามบินเดี๋ยวนี้”

ข้อความเริ่มต้นบนอุปกรณ์เมื่อมีการเตือนดังขึ้น คุณจะได้ยินจุดประสงค์ทันทีแทนที่จะเปิดแอป อ่านป้ายเล็กๆ หรือสงสัยว่าทำไมโทรศัพท์ถึงส่งเสียงดัง มีประโยชน์อย่างยิ่งสำหรับการวิ่งในโรงเรียน การใช้ยา การนัดหมาย การทำอาหาร งานกะ และการเตือนความจำที่แชร์กับครอบครัว

## การสังเกตข้ามคืนอย่างไม่เป็นทางการของเรา: 3% เทียบกับ 10%

ในโทรศัพท์ของเจ้าของ การทดสอบข้ามคืนแสดงให้เห็นว่ามีการใช้แบตเตอรี่ประมาณ 3% เมื่อใช้ Noler เทียบกับประมาณ 10% เมื่อใช้ Alarmy กล่าวอีกนัยหนึ่ง Alarmy ใช้แบตเตอรี่มากขึ้นประมาณ 3.3 เท่าในการสังเกตข้ามคืนนั้น ในขณะที่การระบายของ Noler ลดลงประมาณ 70%

นี่เป็นการเปรียบเทียบโดยตรงในโทรศัพท์เครื่องเดียวกัน แทนที่จะเป็นการรับรองจากห้องปฏิบัติการที่มีการควบคุม ผลลัพธ์ของแบตเตอรี่จะแตกต่างกันไปขึ้นอยู่กับโทรศัพท์ ความสมบูรณ์ของแบตเตอรี่ ระบบปฏิบัติการ ความแรงของสัญญาณ การตั้งค่าการเตือน และคุณสมบัติที่เปิดใช้งาน ไม่รับประกันจำนวนที่แน่นอนในทุกอุปกรณ์ แต่มีเหตุผลในการจัดลำดับความสำคัญของแบตเตอรี่อยู่ในผลิตภัณฑ์

## เครือข่ายน้อยลงหมายถึงการใช้งานแบตเตอรี่น้อยลง

คุณสมบัติพื้นหลังพิเศษทุกอย่างมีค่าใช้จ่าย ต้องดึงข้อมูลสภาพอากาศ ต้องดึงเนื้อหาดูดวง การติดตามการนอนหลับและการกรนจำเป็นต้องมีการตรวจสอบเพิ่มเติม โฆษณาและการวิเคราะห์ต้องใช้โค้ด การรับส่งข้อมูลเครือข่าย และการประมวลผล บัญชีคลาวด์จำเป็นต้องมีการซิงโครไนซ์

Noler จะไม่ดำเนินการใดๆ ในระหว่างการใช้สัญญาณเตือนตามปกติ ไม่จำเป็นต้องมี Wi-Fi หรือข้อมูลมือถือในการจัดเก็บ กำหนดเวลา พูด หรือส่งเสียงปลุก ด้วยการออฟไลน์โดยสมบูรณ์สำหรับงานหลัก จะช่วยหลีกเลี่ยงการปลุกวิทยุเครือข่ายเพื่อดูสภาพอากาศ ดวงชะตา การโฆษณา การวิเคราะห์ บัญชี หรือการรับส่งข้อมูลที่ซิงค์บนคลาวด์

ผลิตภัณฑ์เป็นทางเลือกในการประหยัดแบตเตอรี่ที่คงทนที่สุด: อย่าเริ่มทำงานที่ไม่เกี่ยวข้องตั้งแต่แรก ความรับผิดชอบในเบื้องหลังที่น้อยลงหมายถึงโอกาสในการใช้เวลาของ CPU, เวลา Wi-Fi/วิทยุเคลื่อนที่, หน่วยความจำ และแบตเตอรี่ที่นอกเหนือไปจากงานที่นาฬิกาปลุกต้องการจริงๆ น้อยลง

### วิธีทดสอบการเปรียบเทียบแบตเตอรี่แบบตัวเลข

เครื่องจำลองไม่สามารถเปรียบเทียบแบตเตอรี่โทรศัพท์ได้อย่างถูกต้อง เนื่องจากเครื่องจำลองทำงานบนโปรเซสเซอร์ วิทยุ และแหล่งจ่ายไฟของคอมพิวเตอร์ การอ้างสิทธิ์ "ใช้แบตเตอรี่น้อยลง X เท่า" ในอนาคตจะมาจากการทดสอบอุปกรณ์ทางกายภาพที่ตรงกัน

การวัดประสิทธิภาพจะเรียกใช้ทั้งสองแอปบนรุ่นเดียวกัน เวอร์ชันระบบปฏิบัติการ ช่วงสุขภาพแบตเตอรี่ เครือข่าย ความสว่าง ระดับเสียง และอุณหภูมิ โดยจะวัดสถานการณ์สองสถานการณ์ที่เปิดเผยแยกกัน: การเตือนพื้นฐานที่คล้ายกัน และประสบการณ์เริ่มต้นตามปกติของแต่ละแอป ลำดับการทดสอบจะสลับกัน แอปที่ไม่เกี่ยวข้องจะหยุดทำงาน อุปกรณ์จะเริ่มทำงานที่ประจุและอุณหภูมิเท่ากัน และแต่ละสถานการณ์จะทำซ้ำอย่างน้อยห้าครั้ง

การวัดผล Android จะใช้สถิติแบตเตอรี่ของระบบและข้อมูลพลังงานของฮาร์ดแวร์เมื่อได้รับการรองรับ การวัดค่า iOS จะใช้การติดตามพลังงานของ Instruments บน iPhone จริง ผลลัพธ์จะรายงานระยะเวลาการทดสอบ การตั้งค่าที่แน่นอน ผลลัพธ์พลังงานมัธยฐาน ช่วงการทำงานต่อการทำงาน และไฟล์การติดตามข้อมูลดิบ จนกว่าจะมีหลักฐานที่ได้รับการควบคุม ผลลัพธ์ 3% เทียบกับ 10% ที่เผยแพร่ยังคงระบุอย่างชัดเจนว่าเป็นการสังเกตข้ามคืนของอุปกรณ์จริงของเจ้าของ ไม่ใช่การรับประกันสำหรับโทรศัพท์ทุกเครื่อง

## ส่วนตัวด้วยการออกแบบ

การใช้การเตือนตามปกติจะไม่ส่งข้อมูลการเตือนไปที่ใดเลย

- ไม่มีรหัสโฆษณา
- ไม่มีบัญชีหรือการเข้าสู่ระบบ
- ไม่มี SDK การวิเคราะห์
- ไม่มีการติดตามพฤติกรรม
- ไม่มีการสำรองข้อมูลหรือการซิงโครไนซ์บนคลาวด์
- ไม่มีบริการข้อมูลการเตือนภัยระยะไกล
- ไม่มีคำขอเครือข่ายข้ามต้นทางในเบื้องหลัง

บันทึกการเตือน ป้ายกำกับ การตั้งค่า ไฟล์แนบ คำพูด และกำหนดเวลาการแจ้งเตือนจะยังคงอยู่ในอุปกรณ์ของคุณ หน้าข้อกำหนด ความเป็นส่วนตัว และการสนับสนุนที่ใช้งานอยู่จะเปิดเฉพาะเมื่อคุณเลือกอย่างชัดเจนในการตั้งค่า

## สัญญาณเตือนแบบพูดได้ซึ่งจะอธิบายว่าทำไมจึงดังขึ้น

ติดป้ายกำกับการปลุก เช่น "โรงเรียน" "ยา" "สนามบิน" หรือ "โทรหาแม่" เมื่อเสียงเรียกเข้าดังขึ้น Noler จะสามารถพูดป้ายกำกับนั้นดัง ๆ โดยใช้คำพูดที่มีอยู่ในอุปกรณ์ของคุณ

กลยุทธ์ด้านเสียงบนอุปกรณ์เป็นแบบเฉพาะแพลตฟอร์ม ทั้งสองแพลตฟอร์มใช้การอ่านออกเสียงข้อความของระบบสำหรับป้ายกำกับสัญญาณเตือน บน Android เสียง Flite โอเพนซอร์สแบบรวมที่มีน้ำหนักเบาจะเข้ามาแทนที่เมื่ออุปกรณ์ไม่มีกลไก TTS ของระบบที่ใช้งานได้ เสียงสัญญาณเตือนของระบบปฏิบัติการยังคงเป็นเสียงเตือนชั้นสุดท้าย

เฉพาะ Android มีระบบเสียงโอเพนซอร์ส Flite ในตัว ให้เสียงอังกฤษสำรองเมื่อไม่มีระบบแปลงข้อความเป็นเสียงที่ใช้ได้ เสียงที่เลือกได้ขึ้นอยู่กับภาษาที่ติดตั้ง โหมดคงการทำงานของแอปเป็นตัวเลือกที่ปิดไว้ตั้งแต่ต้น และอาจใช้แบตเตอรี่มากขึ้น

เสียงปลุกสำรองมีไว้เพื่อป้องกันไม่ให้เสียงที่ไม่พร้อมใช้งานส่งเสียงปลุกแบบเงียบ
