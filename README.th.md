ได้ยินทันทีว่าปลุกให้ทำอะไร Noler อ่านชื่อที่คุณตั้งไว้ และเก็บข้อมูลบนอุปกรณ์ ใช้ปลุกตามปกติได้โดยไม่ต่อเน็ต ไม่มีโฆษณา บัญชี หรือค่าสมาชิก

เริ่มเช้าด้วยข้อความที่เข้าใจได้ ตั้งชื่อปลุกว่า “ถึงเวลาไปทำงาน” หรือ “ออกไปสนามบิน” แล้ว Noler จะอ่านด้วยระบบเสียงบนอุปกรณ์ นาฬิกาปลุกขนาดเบาสำหรับตื่นนอนและเตือนกิจวัตรประจำวัน

ตั้งปลุกครั้งเดียวหรือปลุกซ้ำในวันที่เลือก ดูเวลาปลุกถัดไปได้ทันที พร้อมปุ่มใหญ่สำหรับเลื่อนปลุกและหยุด หากใช้เสียงพูดไม่ได้ จะมีเสียงปลุกเป็นทางเลือกสำรอง

การใช้ปลุกตามปกติทำงานออฟไลน์ทั้งหมด ไม่ต้องใช้ Wi-Fi หรือข้อมูลมือถือ ตารางปลุก เสียงพูด ประวัติ การตั้งค่า และไฟล์แนบอยู่บนอุปกรณ์ ไม่มีโฆษณา การวิเคราะห์การใช้งาน การติดตามพฤติกรรม บัญชี การซิงค์คลาวด์ การสมัครสมาชิก หรือการซื้อในแอป

ใส่ใจแบตเตอรี่ด้วยการลดงานที่ไม่จำเป็น Noler ไม่มีข้อมูลอากาศ ดวงชะตา โฆษณา การวิเคราะห์ การซิงค์คลาวด์ หรือฟีดออนไลน์เบื้องหลัง จึงไม่ต้องรับส่งและประมวลผลข้อมูลของบริการเหล่านั้น การใช้แบตเตอรี่จริงขึ้นอยู่กับอุปกรณ์ การตั้งค่า และการใช้งาน ไม่รับประกันตัวเลขการประหยัดที่แน่นอน

แกนแอปและหน้าจอที่ใช้ร่วมกันพัฒนาด้วย Rust และ Dioxus มีตัวเลือกภาษาและภูมิภาคของหน้าจอ 39 แบบ ไม่มีติดตามการนอน บันทึกเสียงกรน หรือฟีดข่าว

เฉพาะ Android มีระบบเสียงโอเพนซอร์ส Flite ในตัว ให้เสียงอังกฤษสำรองเมื่อไม่มีระบบแปลงข้อความเป็นเสียงที่ใช้ได้ เสียงที่เลือกได้ขึ้นอยู่กับภาษาที่ติดตั้ง โหมดคงการทำงานของแอปเป็นตัวเลือกที่ปิดไว้ตั้งแต่ต้น และอาจใช้แบตเตอรี่มากขึ้น

หน้าออนไลน์ในการตั้งค่า เช่น ข้อกำหนดและความเป็นส่วนตัว จะเชื่อมต่อเมื่อคุณเลือกเปิดเท่านั้น
