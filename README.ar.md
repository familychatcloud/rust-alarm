اسمع سبب رنين المنبه فورًا. يقرأ Noler اسم المنبه ويحفظ بياناتك على جهازك. بلا إعلانات أو حساب أو اشتراك، مع تشغيل المنبهات دون إنترنت.

ابدأ صباحك برسالة واضحة. سمِّ المنبه «حان وقت العمل» أو «الانطلاق إلى المطار» وسيقرأ Noler الاسم بصوت مسموع باستخدام النطق المتاح على جهازك. منبه ناطق خفيف للمواعيد اليومية والاستيقاظ.

اضبط منبهًا لمرة واحدة أو كرره في أيام الأسبوع التي تختارها. اعرف موعد المنبه التالي بنظرة واحدة، واستخدم أزرارًا كبيرة للغفوة والإيقاف. إذا تعذر النطق، يتوفر صوت منبه بديل.

الاستخدام المعتاد للمنبه يعمل بالكامل دون اتصال، فلا يحتاج إلى Wi-Fi أو بيانات الهاتف. تبقى المواعيد والنطق والسجلات والإعدادات والمرفقات على جهازك. لا إعلانات أو تحليلات استخدام أو تتبع سلوكي أو حساب أو مزامنة سحابية أو اشتراكات أو مشتريات داخل التطبيق.

الاهتمام بالبطارية يبدأ بتقليل المهام. لا يجلب Noler الطقس أو الأبراج أو الإعلانات أو التحليلات أو المزامنة السحابية أو أي موجزات إنترنت في الخلفية، فيتجنب حركة الشبكة والمعالجة المرتبطة بها. يختلف الاستهلاك حسب الجهاز والإعدادات والاستخدام؛ لا نَعِد بنسبة توفير ثابتة.

بُنيت نواة التطبيق وواجهته المشتركتان باستخدام Rust وDioxus، مع 39 خيارًا للغة والمنطقة في الواجهة. لا تتبع للنوم أو تسجيل للشخير أو موجز أخبار.

على Android فقط، يوفر محرك Flite المفتوح المصدر والمضمّن صوتًا إنجليزيًا بديلًا إذا لم يتوفر محرك نطق صالح في النظام. تعتمد الأصوات على اللغات المثبتة. وضع إبقاء التطبيق نشطًا اختياري ومعطّل افتراضيًا وقد يزيد استهلاك البطارية.

صفحات الإنترنت في الإعدادات، مثل الشروط والخصوصية، لا تُحمَّل إلا عندما تختار فتحها.
