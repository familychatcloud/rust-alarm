# 무료 Rust 알람 시계 — 광고 없음, 추적 없음, 부풀림 없음

### iPhone, iPad 및 Android용 경량 오프라인 통화 알람.

## 알람이 울리는 이유를 들어보세요.

의미 없는 벨소리에 깨어나지 마세요. Noler는 '학교에 가자', '약을 먹어라', '공항으로 출발' 등 내가 쓴 라벨을 말합니다. 반쯤 자고 있을 때에도 목적을 즉시 들을 수 있습니다.

## 이 Rust 알람을 선택하는 이유는 무엇입니까?

- 광고도 없고, 구독도 없고, 인앱 구매도 없고, 계정도 없고, 분석도 없고, 행동 추적도 없습니다.
- 일반적인 알람 사용은 완전히 오프라인입니다. 알람, 라벨, 설정, 음성 및 예약은 Wi-Fi 또는 모바일 데이터 없이 장치에 유지됩니다.
- 알람 뒤에 실행되는 날씨, 운세, 뉴스, 수면 추적, 코골이 녹음, 광고 또는 클라우드 동기화 작업 부하가 없습니다.

## 작고 집중적입니다.

현재 iOS 패키지는 11.5MB인데 비해 Alarmy는 237.5MB입니다. 20배 더 작습니다. Noler의 현재 Google Play에 업로드된 Android App Bundle은 5.6MB입니다.

## 배터리 절약이 우선입니다.

소유자의 동일한 휴대폰 야간 테스트에서 Noler는 약 3%의 배터리를 사용했는데, 이는 Alarmy의 10%에 비해 밤새 소모량이 약 3배 더 낮습니다. 결과는 장치 및 설정에 따라 다르지만 Noler는 추가 기능에 필요한 네트워킹 및 백그라운드 작업을 방지합니다.

## 39개의 인터페이스 로케일 및 24개의 알람 음성 선택

이 앱은 32개의 언어에 걸쳐 39개의 UI 로케일 선택을 제공합니다. 알람 라벨은 장치에서 사용할 수 있는 24가지 음성 언어 선택을 사용하여 말할 수 있습니다.
