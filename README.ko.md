아침에 알람이 왜 울리는지 바로 들어 보세요. Noler가 알람 이름을 읽어 주고 데이터를 기기에 보관합니다. 평소 알람 사용은 오프라인이며 광고, 계정, 구독이 없습니다.

벨소리와 함께 알람의 용도까지 알아보세요. 알람 이름을 “출근할 시간” 또는 “공항으로 출발”로 정하면 Noler가 기기의 음성 기능으로 읽어 줍니다. 기상과 일상 일정에 필요한 가벼운 음성 알람입니다.

한 번만 울리는 알람이나 원하는 요일에 반복되는 알람을 설정하세요. 다음 알람을 한눈에 확인하고 큰 버튼으로 다시 알림과 끄기를 조작할 수 있습니다. 음성을 사용할 수 없으면 알람 소리가 대체 수단이 됩니다.

일반적인 알람 사용은 완전히 오프라인입니다. 예약, 이름, 음성, 기록에 Wi-Fi나 모바일 데이터가 필요하지 않습니다. 알람, 설정, 첨부 자료는 기기에 저장됩니다. 광고, 사용 분석, 행동 추적, 계정, 클라우드 동기화, 구독, 앱 내 구매가 없습니다.

배터리를 고려해 불필요한 작업을 줄였습니다. 날씨, 운세, 광고, 분석, 클라우드 동기화 등 온라인 정보를 백그라운드에서 가져오지 않아 해당 서비스의 통신과 처리 작업을 피합니다. 실제 배터리 사용량은 기기, 설정, 사용 방식에 따라 달라지며 일정한 절약 효과를 보장하지 않습니다.

공통 앱 핵심 기능과 인터페이스는 Rust와 Dioxus로 만들었습니다. 인터페이스는 39개 언어·지역 옵션을 제공합니다. 수면 추적, 코골이 녹음, 뉴스 피드는 포함하지 않습니다.

Android에서만 시스템 음성 엔진을 사용할 수 없을 때 내장된 오픈소스 Flite 엔진이 영어 대체 음성을 제공합니다. 사용 가능한 음성은 설치된 언어에 따라 다릅니다. 선택 사항인 앱 유지 모드는 기본적으로 꺼져 있으며 켜면 배터리 사용량이 늘 수 있습니다.

설정의 이용약관이나 개인정보 처리방침 같은 온라인 페이지는 직접 열 때만 인터넷으로 불러옵니다.
